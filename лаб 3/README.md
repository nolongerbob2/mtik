# Лабораторная работа 3

Разработка синтаксического анализатора. Кожемякин Даниил Сергеевич, группа 231-3213.

`syntaxAnalyzer.cpp` содержит листинг из отчёта: рекурсивный спуск, построение абстрактного синтаксического дерева и сохранение AST в JSON.

## Сборка

Из этой папки, компилятором с поддержкой C++20:

```sh
g++ -std=c++20 syntaxAnalyzer.cpp -o syntaxAnal
```

Либо через CMake:

```sh
cmake -S . -B build
cmake --build build
```

## Запуск

Вход — текстовый список токенов вида `(KEYWORD, int)`, `(IDENTIFIER, main)`, `(DELIMITER, ()`. Формат соответствует функции `print_list` лексического анализатора из ЛР2; таблица лексем и диагностические сообщения во входной файл не включаются.

```sh
./syntaxAnal preprocessed_test.c_tokens.txt
```

Для указанного имени входного файла результат сохраняется в `syntaxAnal_test.json` в текущей папке. Этот JSON передаётся семантическому анализатору из ЛР4.

На Windows имя исполняемого файла — `syntaxAnal.exe`. При сборке через CMake исполняемый файл находится в каталоге сборки, а для некоторых генераторов — в подкаталоге конфигурации.

Анализатор рассчитан на подмножество языка из отчёта: переменные `int`, целочисленные и строковые литералы, функции и их прототипы, присваивание, арифметические выражения, сравнения `>`, `<`, `<=`, блоки `if/else`, цикл `for` и `return`. Остальные конструкции C и C++ требуют расширения грамматики.
